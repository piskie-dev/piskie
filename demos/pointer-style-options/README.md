# 虚拟光标样式对比

直接用浏览器打开 `index.html`。页面无构建步骤、无外部资源，也可以通过独立静态服务器预览。

| 编号 | 样式 | 区别 |
| --- | --- | --- |
| A | 经典白 | 标准白色箭头，黑白双边，清晰稳定 |
| B | 纤影灰 | 更窄的斜向箭头，低饱和灰与细白轮廓 |
| C | 暖杏 | 紧凑折面箭头，温暖杏色与浅色高光 |
| D | 雾蓝 | 短尾三角箭头，柔和蓝色玻璃感 |
| E | 珍珠点 | 约 10px 的可见圆点，中心定位 |
| F | 细准星 | 16px 分段准星，中心点与留白 |

主页面展示真实尺寸与 3 倍正常 / 按下轮廓；“放大对比”展示 6 倍轮廓，并可切换浅色、深色、图片背景。图片由本地 SVG 绘制。六款使用同一条路线与同一时钟：移动 120ms、到达后按下、点击环 360ms。所有交互只作用于本页的虚构按钮。

“暂停”会同时冻结位置、按下状态和点击环；“播放”继续；“重播”从起点播放；“定格点击”停在按钮的按下状态。点击任意演示按钮也会让六款同步定格到同一个落点。系统偏好减少动态效果时默认暂停，仍可手动播放。放大对比可用关闭按钮或 Escape 退出。

文件：

- `index.html`：页面与六款原始 SVG 轮廓。
- `styles.css`：展示布局、正常 / 按下样式与背景。
- `demo.js`：本页比较控制与同步动画。
- `assets/landscape.svg`：本地风景背景。

这些文件是独立样式提案。用户选定款式后再考虑产品实现；本轮不替换正式光标。
