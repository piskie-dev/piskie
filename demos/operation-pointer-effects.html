展开完整效果范围与共用关系
位置与真实鼠标

初始化常驻、平滑移动、最新目标接续、悬停、拖拽、单击、双击。悬停共用移动；拖拽共用真实按下 / 按住 / 释放。

控件目标

输入框、多行文本、富文本、连续填表、下拉选择、可见上传共用目标轻框。图标表示输入 / 选择 / 上传；隐藏上传只显示状态。

键盘与焦点

Tab 与普通按键定位真实焦点；无可见焦点时显示键盘状态。脚本引起的可见焦点使用相同轻框，并保留通用操作状态。

滚动提示

纵向、横向、按键引起的滚动共用上下箭头状态图标。页面内容按实际方向变化，状态图标本身没有额外方向动画。

没有网页落点的操作

导航显示导航状态；等待、读取 / 截图 / 提取、存储、窗口和原生对话框共用操作状态。读取保持位置；新页初始化，切回恢复已知位置。

手动与部分可见

手动为 0ms 立即跟随，并带手形标记。部分可见控件在可见区域定位；目标框暂时隐藏时，箭头仍保留该控件位置。
